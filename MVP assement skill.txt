# ABA Clinical Assessment & Goal Generation Engine — Skill File

**Version:** 1.0.0  
**Target Agent:** Code Generation / Implementation Agent  
**Goal:** Build a system where a therapist assesses a learner, enters assessment data, and the system systematically scores, evaluates, flags deficits, and suggests goals.

---

## 1. Purpose

Create a clinical platform for ABA professionals (BCBA, BCaBA, RBT, Behavior Therapist) that:

1. Provides a **structured assessment form** for VB-MAPP-style and ABLLS-R-style grids.
2. Accepts **therapist-entered scores**.
3. **Aggregates scores** by item, domain, level, and attempt.
4. **Visualizes** results in a Master Grid with color-coded blocks.
5. **Evaluates** performance using deterministic clinical rules.
6. **Flags deficits** automatically.
7. **Suggests goals** from a universal goal bank.
8. **Generates reports** (SOAP notes, progress reports).

The system does **not** administer the assessment or replace clinical judgment. It is a score-entry, aggregation, evaluation, and reporting engine.

---

## 2. System Architecture

- **Architecture Type:** Neutral Score-Entry and Visualization Engine
- **Compliance Note:** Avoid third-party copyrighted text. Use generic domain names and scoring structures. Do not embed proprietary question stems.
- **Supported Frameworks:** VB-MAPP Grid Mapping Strategy, ABLLS-R Grid Tracking Strategy.
- **Target Users:** BCBA, BCaBA, RBT, Behavior Therapist.

### 2.1 High-Level Flow

```
Therapist assesses learner
        ↓
Therapist enters scores into form
        ↓
System validates and stores scores
        ↓
System aggregates scores (item → domain → level → attempt)
        ↓
System applies evaluation rules
        ↓
System flags deficits
        ↓
System suggests goals from goal bank
        ↓
System generates reports / grid visualization
```

- **BehaviorData:** `BehaviorID`, `SessionID`, `BehaviorName`, `Frequency`, `Duration`, `ABC_Antecedent`, `ABC_Behavior`, `ABC_Consequence`.

## 4. Workflow

### Step 1: Therapist Assesses Learner
- Therapist selects a learner.
- Therapist selects assessment type (VB-MAPP_GRID or ABLLS_GRID).
- Therapist selects attempt number (1–4).
- System loads the appropriate grid structure.

### Step 2: Therapist Enters Data
- System displays an **Assessment Form** with domains, items, and score inputs.
- For VB-MAPP: score options `0.0`, `0.5`, `1.0`.
- For ABLLS: score options `0`, `1`, `2`, `3`, `4`.
- Therapist enters scores for each item.
- Optional: notes per item.

### Step 3: System Validates and Stores
- Validate all required fields.
- Store `AssessmentRecord` and `ScoreEntry` records.
- Calculate domain totals, level totals, percentages.

### Step 4: System Evaluates
- Apply **Mastery Rule**, **Lack of Progress Rule**, **Regression Rule**.
- Compare current attempt to previous attempts.

### Step 5: System Flags Deficits
- Any item with score < max score is a deficit.
- Any domain with total < max domain score is a domain deficit.
- Categorize: Acquired, Emerging, Deficit.

### Step 6: System Suggests Goals
- Map deficits to **Universal Goal Bank**.
- Suggest goals based on domain and deficit severity.
- Allow therapist to accept, modify, or reject.

### Step 7: System Generates Reports
- SOAP note.
- Progress report with graphs.
- Mastery summary table.

## 6. Scoring & Aggregation Logic

### 6.1 Item Score
- VB-MAPP: `0.0`, `0.5`, `1.0`
- ABLLS: `0`, `1`, `2`, `3`, `4`

### 6.2 Domain Total
- Sum of item scores in domain.
- VB-MAPP: max = `total_items * 1.0` (e.g., 5 items → max 5.0)
- ABLLS: max = `total_items * 4` (e.g., 5 items → max 20)

### 6.3 Domain Percentage
```
percentage = (domain_total / domain_max) * 100
```

### 6.4 Level Total
- Sum of all domain totals in level.

### 6.5 Attempt Comparison
- Store each attempt separately.
- Calculate change: `current_percentage - previous_percentage`.

## 7. Evaluation & Flagging Rules

### 7.1 Mastery Rule

**Condition:**
- `independent_responses >= 80%`
- `consecutive_sessions >= 3`
- `minimum_therapists >= 2`

**Action:**
- `FLAG_GOAL_AS_MASTERED`
- Notification: "Mastery criteria reached for this target. Review for Generalization."

### 7.2 Lack of Progress Rule

**Condition:**
- `zero_or_negative_trend`
- `consecutive_sessions >= 6`

**Action:**
- `FLAG_GOAL_FOR_REVISION`
- Notification: "Lack of progress detected over 6 sessions. Clinical review recommended."

### 7.3 Regression Rule

**Condition:**
- `drop_below_60_percent_after_mastery`
- `consecutive_sessions >= 2`

**Action:**
- `FLAG_REGRESSION`
- Notification: "Performance regression flagged in maintenance phase."

### 7.4 Deficit Detection

- **Item Deficit:** `score < max_score_for_item`
- **Domain Deficit:** `domain_total < domain_max`
- **Skill Deficit Auto-Detector:** flag any item scoring less than maximum for IEP Goal Generation.

3. Rank by severity (percentage below max).
4. Present top N goals to therapist.

## 9. Reporting Engine

### 9.1 SOAP Note

- **S (Subjective):** Therapist enters summary of client demeanor.
- **O (Objective):** Auto-populated numerical data table (Total Mands, Behavior Frequencies, Mastery Updates).
- **A (Assessment):** Auto-calculated percentage changes vs baseline and prior week average.
- **P (Plan):** System recommendation to continue current BIP or trigger BCBA review.

### 9.2 Progress Report

- **Executive Summary:** Auto-generated narrative based on active vs mastered goals count.
- **Visual Graphs:** Line charts with phase change lines for all BIP and Skill goals.
- **Mastery Summary Table:** List of all goals achieved in reporting window with dates.

## 10. Technical Implementation Guidelines

### 10.1 Database Schema

**SQL Example:**

```sql
CREATE TABLE Learner (
  LearnerID INT PRIMARY KEY,
  Name VARCHAR(100),
  DOB DATE,
  Diagnosis VARCHAR(100)
);

CREATE TABLE Assessor (
  AssessorID INT PRIMARY KEY,
  Name VARCHAR(100),
  Role VARCHAR(50)
);

CREATE TABLE AssessmentRecord (
  AssessmentID INT PRIMARY KEY,
  LearnerID INT,
  AssessorID INT,
  Date DATE,
  AssessmentType VARCHAR(20),
  AttemptNumber INT,
  FOREIGN KEY (LearnerID) REFERENCES Learner(LearnerID),
  FOREIGN KEY (AssessorID) REFERENCES Assessor(AssessorID)
);

CREATE TABLE ScoreEntry (
  ScoreID INT PRIMARY KEY,
  AssessmentID INT,
  ItemCode VARCHAR(20),
  Score DECIMAL(3,1),
  Level INT,
  DomainCode VARCHAR(20),
  AssessmentAttempt INT,
  FOREIGN KEY (AssessmentID) REFERENCES AssessmentRecord(AssessmentID)
);

CREATE TABLE Goal (
  GoalID INT PRIMARY KEY,
  LearnerID INT,
  TargetID VARCHAR(20),
  Status VARCHAR(20),
  MasteryDate DATE,
  Notes TEXT,
  FOREIGN KEY (LearnerID) REFERENCES Learner(LearnerID)
);
```
