 THE PRIORITIZED FIX LIST ("what to build next")
=====================================================================

P0 — ONE FIX UNLOCKS FOUR PERSONAS' ASKS: REAL EMAIL DELIVERY
  Wire an email provider (Resend / SendGrid / Postmark) into the
  existing sendPasswordResetEmail, which currently only prints to
  the server log. This single connection closes:
   - Admin #5/#9   (password babysitting, staff invites)
   - Therapist #9  (reset email she never gets today)
   - Parent #9     (part of the welcome experience)
  AND becomes the backbone for the notification features:
   - Admin #6/feed (pending-notes digest, trial-expiry email)
   - Parent #7     (session reminders, cancellation alerts)
  NOTE: this is a third-party service choice — it needs to be
  researched and picked (Gravity search) before wiring.

P1 — HIGHEST-VALUE FEATURES STILL MISSING
  1. Parent progress report PDF export (admin top-5 #2 AND
     supervisor top-5 #7 — one page serves both personas)
  2. Notifications: cancellations + reminders (parent) and a
     pending-notes digest for admins; rides on P0
  3. Parent invoice visibility in the portal

P2 — QUALITY OF LIFE
  4. Center Settings page (name, logo, hours, timezone —
     timezone labels fix parent #10 at the same time)
  5. Staff invite email + forced first-login password change
  6. "Re-assign today's sessions" quick action (staff absence)
  7. Bulk co-sign button in the Lookout queue
  8. Save/retry (sync) state for flaky Wi-Fi during sessions

P3 — BIG LIFTS (plan consciously)
  9.  Phone-responsive session flow / real mobile app
      (therapist's #1 ask — decide native vs. responsive web)
  10. Availability-aware calendar
  11. Learning-curve charts per target (prompt fading)
  12. Data-quality / implausible-data flags
  13. Home-activities feed for parents
  14. Per-session auto-generated parent summary

=====================================================================
 BOTTOM LINE
=====================================================================
 - The supervisor persona is already best-in-class; his remaining
   gaps are polish (bulk co-sign, charts, PDF).
 - The app meets most of the parent experience already (portal,
   glossary, progress, messages, documents) — what's missing is
   mostly COMMUNICATION (email + notifications).
 - The therapist is the least served going forward: her #1 ask
   (phone-friendly session flow) is the largest open item.
 - RECOMMENDED ORDER: P0 email provider -> PDF report ->
   notifications -> parent invoices -> Settings -> the rest.
